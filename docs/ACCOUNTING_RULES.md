# 财务与库存核算约束

## 权责发生制与三流分离

业务事实（采购、收货、销售、出库、费用）、资金流水（银行/现金）和税务凭证（发票/认证）必须分别记录，以稳定 ID 关联。认领银行流水仅结清对应应收应付或记入待分类科目，不凭流水直接确认收入费用；认领发票不代表已抵扣，须另记录税务用途和认证状态。系统内状态标记为“已认证”需录入用户核验的税务机关确认依据；内部台账不自行调用税局或生成抵扣分录。

## 自动分录基本口径

- 成品/包装采购验收入库：借记存货（不含税）；符合确认条件的可抵扣税额单独列项；贷记应付。未收到合规凭证时，不得虚构待抵扣进项税。
- 采购原币必须是三位 ISO 币种代码；CNY 采购固定使用汇率 1，外币采购须记录有效汇率日期和正汇率，按本位币折算确认存货与应付。
- 付款：借记应付、贷记银行；不得再次进入损益。
- 经营费用按发生日确认：借记对应费用科目、贷记应付；付款流水只核销应付。费用登记金额按确认可计入损益的人民币金额录入，税票和抵扣状态独立记录。
- 公共经营费用可按人民币金额分批分摊至同一经营主体下的项目。分摊须在未关账期间生成借贷平衡的费用重分类分录，并保留分录行级业务线、主体和项目维度；项目借方与原公共费用贷方抵销，公司合并费用总额不变。分摊总额不得超过来源费用，已归属项目的费用不可再作为公共费用分摊。
- 未关账的项目分摊可按原分摊记录部分或全部撤回。撤回使用独立稳定来源键、留存日期与操作人字段，生成与原分摊相反的维度凭证，并把撤回金额退回来源费用的可分摊余额；累计撤回不得超过该笔原分摊金额。操作人字段尚未接入认证，不能作为具名审计凭据。
- 销售履约确认：按不含增值税金额确认收入；同步按库存计价方法借记主营业务成本、贷记存货。未开票销售也必须确认业务收入和成本。
- 销售退货：关联原销售行和原 FIFO 批次，按实际退回成品及包装数量恢复原库存层成本；借记收入冲减，未收款部分贷记应收，已收款部分转为应付客户退款；同时借记存货、贷记销售成本。缺失原批次成本关联时必须人工复核，不得按当前成本估值。
- 展会样品发出：按原 FIFO 批次成本借记项目样品费用、贷记存货；完好样品归还时按对应批次成本冲回费用并恢复原库存层。预算记录只用于执行比较，不再形成第二笔费用。
- 自行车以 ALSVID 采购引用为批次边界，不复制 VIN。用户按稳定外部来源键确认实收数量；合同金额及已登记可资本化费用按订单数量等额形成 CNY 存货成本。销售只能使用实收未售数量，按同一批次成本结转，并按原币和汇率确认 CNY 收入/应收。进口增值税不计成本、不自动抵扣。费用在销售后补录的调整、外币收入期末重估和银行对账调节需单独复核，目前不自动处理。
- 进项税进入待认证、已认证可抵扣、不得抵扣等明确状态；发票勾选只是内部关联。
- 无法识别用途的银行流水进入待分类/暂记科目，不能丢弃或臆分损益。
- 外币银行流水与外币应收应付分别保留原币和经复核汇率折算的 CNY 账面余额；结算时比较银行实际折算额与往来账面额，差额记入已实现汇兑损益，不并入经营利润。历史外币记录缺少汇率时必须人工补录汇率日期和依据，禁止推算。

## 存货成本

所有出入库通过不可变库存流水追溯。重复导入使用来源系统、文件/批次和来源行稳定键防重。销售退货按原成本冲回；负库存、缺成本批次和 SKU 包装规则缺失必须报错或进入待复核队列，不得静默估算。包装用量由 SKU 规则决定；已含包装的成品不重复扣盒。采购、海运、关税等可归属成本依事先确定的分摊基准进入批次成本，进口增值税不进入成本。

## 维度、汇总与期间

统一使用业务线、经营主体、往来单位、商品/SKU、仓库、币种、项目/展会、期间等维度。展会费用在明细上保留项目归属，汇总公司利润时不得与业务成本重复相加。报表分别列示毛利、经营费用和经营利润；预算执行与实际损益不能混为一项。

实时期间标记为预估。关账前允许按权限更正并留审计历史；关账保存期间状态、确认人和时间，后续改动走冲销/调整流程并保留原凭证。金额使用定点十进制；外币保存原币金额、币种、汇率来源/日期与本位币金额。

## 必须成立的账务不变量

1. 每张已过账凭证借贷合计相等。
2. 每个分摊的已用金额不超过来源流水/发票及业务单据可分摊余额。
3. 已确认销售收入与销售成本具有同一履约来源和期间依据。
4. 库存结存等于期初加全部入库、减全部出库，并能追溯来源。
5. 已关账期间不接受原位覆盖；更正必须可追溯。


## 个人垫付 → 财务确认 → 公司报销（V43）

1. 个人用自己的银行卡/现金为公司业务付款时，不将这条**个人账户流水**导入公司银行流水池。
2. 进入「财务中心 → 经营费用 → 个人垫付与公司报销」登记垫付人、实际商家、原始付款日期、金额、项目归属和付款凭证。**提交时为待审核状态，不记账**。
3. 财务审核确认（选择未关账的入账日期）：
   - **新发生的经营费用**：借记经营费用、贷记应付账款；记录商家应付已由个人代付，再借记商家应付、贷记对垫付人的应付。费用只记一次，供应商仍可正常关联进项发票。
   - **已存在采购/费用应付**：仅将供应商应付转到垫付人应付，不重新确认采购成本、库存或费用。
4. 公司以后从**公账**给个人转账，月度导入公司银行流水，然后认领到该垫付人的应付账款。分批报销可累计核销，银行会计分录借记应付账款、贷记银行存款。
5. 独立显示「待审核 / 待报销 / 部分已报销 / 已报销」，报销状态来源于真实银行核销金额，不能靠手工选择“已完成”。
6. **个人付款凭证 ≠ 进项发票**。税务发票仍通过发票池单独登记、验证和关联供应商应付。个人代付不自动触发进项抵扣。
7. 当前 V43 仅自动支持人民币 CNY。外币个人垫付款在汇率与账面价值审核机制落地前不能擅自按 1:1 转换。
8. 原始文件必须实际归档后才允许生成垫付草稿。记账日期受月结锁限制，修改已封账期间的历史费用不允许被自动回写。
